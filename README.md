# Assignment 5 — Study Desk

Daniyal Akylbek | SE-2530 

https://ddsu5.github.io/web-asn-05/
A four-page JavaScript practice project covering Tasks 0–8: variables, DOM manipulation, events, a calculator and an interactive To-Do list. Built with HTML, CSS and plain JavaScript. No installation, framework, CDN or database is needed.

## Run

Extract the ZIP, then open `index.html` in a browser. Click OK on the required greeting alert. Use the navbar to move between all four pages. Press F12 and select Console to view the name, group, variable values, arithmetic results and concatenated sentence.

## Files and requirements

| Task | Page | Script | What to demonstrate |
| --- | --- | --- | --- |
| 0 | index.html | js/basics.js | External script, console name/group, exact greeting alert |
| 1 | index.html | js/basics.js | String, number, boolean; +, -, *, /, %; string concatenation |
| 2 | dom.html | js/dom.js | Change paragraph text with a button |
| 3 | dom.html | js/dom.js | Separate buttons change the div background and font size |
| 4 | dom.html | js/dom.js | Add an li and remove the last li; empty-list guard |
| 5 | events.html | js/events.js | mouseover changes color; mouseout restores it |
| 6 | events.html | js/events.js | keyup shows current input; input also supports paste |
| 7 | events.html | js/events.js | Addition, subtraction, multiplication, division; input validation |
